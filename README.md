# skills

Colección de skills para agentes. Una carpeta por skill.

## Skills

| Skill | Qué hace |
|---|---|
| [`apuntes/`](apuntes/) | Convierte un PDF en apuntes de estudio autocontenidos: portada, índice, pestañas y hojas con bloques de definición, tips, cuidados y pasos. Un solo `.html`, funciona sin internet. |

## Instalación

Copiá la carpeta de la skill a `~/.agents/skills/`:

```sh
cp -r apuntes ~/.agents/skills/
```
